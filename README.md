# 🛡️ License Reminder CLI

![.NET Version](https://img.shields.io/badge/.NET-8.0-blueviolet)
![Maintained](https://img.shields.io/badge/Maintained-Yes-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

A professional .NET Console Application designed to automate the reconciliation of driver's license expirations and employee contact data. It manages automated email notifications and ensures data consistency across multiple CSV sources.

## 🚀 Architecture Overview

The project follows **Clean Architecture** principles and **SOLID** patterns, organized into three main layers:

- **AvvisoScadenzaPatenti.Core**: Domain Models, Repository Interfaces, and Business Logic (Orchestrator, fiscal code decoding, license sorting).
- **AvvisoScadenzaPatenti.Infrastructure**: Data access (CSV flat files), Email services (MailKit), and Security (Base64/Data Protection).
- **AvvisoScadenzaPatenti.Cli**: The entry point managing Dependency Injection (Microsoft.Extensions), Configuration, and Command Line parsing. Each CLI mode (sort, search, update, fiscal code matching, etc.) is implemented as a dedicated `ILicenseCommand` under `Cli/Commands`, keeping `Program.cs` limited to bootstrap and dispatch.

## 🛠 Tech Stack

- **Framework:** .NET 8.0 (LTS)
- **CSV Parsing:** [CsvHelper](https://joshclose.github.io/CsvHelper/)
- **Email:** [MailKit](http://www.mimekit.net/)
- **CLI Parsing:** [CommandLineParser](https://github.com/commandlineparser/commandlineparser)
- **DI & Hosting:** Microsoft.Extensions.Hosting
- **Logging:** [Serilog](https://serilog.net/)

## 📋 Features

- **Data Reconciliation**: Cross-references License CSV data with Employee CSV records.
- **Smart Contact Lookup**: Handles uncompliant email addresses via a dedicated lookup table.
- **Auto-Provisioning**: Automatically creates new employee records if they are missing from the database.
- **Secure Storage**: Includes a utility to encrypt sensitive passwords directly into `appsettings.json`.
- **Fuzzy Name Search**: Token-based search for licenses by employee name, tolerant of word order and partial matches.
- **Fiscal Code Matching**: Decodes an Italian *Codice Fiscale* and matches it against employee records, with homonym resolution when multiple candidates are found.
- **Upcoming Expirations Report**: Lists the next N licenses due to expire, flagging any already past due.

## 🗂️ Data Sources

The application reads and writes two distinct CSV files, which are **not interchangeable**:

- `employees.csv` — persistent, grows incrementally over time. Manually-entered data (birth date, fiscal code, contact overrides) belongs here.
- `licenses.csv` — regenerated by an external system on each run. It must never contain manually entered data, as it will be overwritten.

## ⚙️ Installation & Setup

1. **Clone the repository**:

```bash
git clone https://github.com/rcorra68/license-reminder.git
cd license-reminder
```

2. **Restore dependencies**:

```bash
dotnet restore
```

3. **Configure the application**:

Update `src/AvvisoScadenzaPatenti.Cli/appsettings.json` with your SMTP settings and CSV file paths, or generate a default configuration file (see below).

## 🚀 Usage

### Run the application

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj
```

Runs the default reconciliation pipeline: reads licenses and employees, sends expiration notifications, and generates the final report.

### Show help

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --help
```

### ⚙️ Initialize configuration

Generates a default `appsettings.json` with placeholder SMTP settings and CSV paths.

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --init
```

Use `--force` to overwrite an existing configuration file:

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --init --force
```

### 📊 Sort and persist license CSV

Sorts the license CSV file and overwrites it with the ordered data.

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --sort-by [Name|ExpiryDate|ReleaseDate] --sort-order [Asc|Desc]
```

### 🔎 Search a license by employee name

Fuzzy, token-based search — matches on partial names and is tolerant of word order.

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --name "<query>"
```

If multiple licenses match, use `--update-license <number>` to target the correct one.

### 📅 Show upcoming expirations

Lists the next `N` licenses closest to expiring, ordered by expiration date. Already-expired licenses are included and flagged with `[SCADUTA]`.

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --upcoming-expirations <N>
```

### ✏️ Update a license expiry date

Show the current expiration date for a given license number:

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --update-license <number>
```

Update it to a new date (format `yyyy-MM-dd`):

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --update-license <number> --new-expiry-date <yyyy-MM-dd>
```

### 🪪 Match employee by fiscal code

Decodes an Italian *Codice Fiscale* and matches it against employee records by surname/name code, enriching the matched record with the fiscal code and extracted birth date.

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --match-cf <codice-fiscale>
```

If multiple homonym candidates are found, they are listed with an index. Use `--resolve-index` to pick which one to update:

```bash
dotnet run --project src/AvvisoScadenzaPatenti.Cli/AvvisoScadenzaPatenti.Cli.csproj -- --match-cf <codice-fiscale> --resolve-index <N>
```

## 🔐 Security & Configuration

This project supports two ways to manage sensitive information (like SMTP passwords), depending on the environment.

### 1. Local Development (Windows / macOS)

We use the native **.NET Secret Manager** to keep credentials out of the source code. This is the preferred method for local development.

To set up your local secrets:

```bash
# Initialize secrets for the project
dotnet user-secrets init --project src/AvvisoScadenzaPatenti.Cli/

# Set your SMTP credentials
dotnet user-secrets set "Settings:Smtp:Username" "your_email@example.com"
dotnet user-secrets set "Settings:Smtp:Password" "your_secure_password"
dotnet user-secrets set "Settings:Smtp:Host" "your.domain.com"
dotnet user-secrets set "Settings:AdminEmail" "admin_email@example.com"
```
